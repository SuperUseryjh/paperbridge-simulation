纸桥物理模拟系统

基于有限元模拟的纸桥承载计算

灰掉的参数与当前结构方案无关；改任意一项都会立即重算。

动画与显示

当前不是自建结构。切到 ① 方案 → 自定义结构（自己搭建） 即可在画布上搭建。

放节点 / 拖节点

  1. 在空白处单击 → 放一个新节点
  2. 按住已有节点拖动 → 移动它，松手后自动重算

节点的横坐标范围决定跨长；位置摆不平也没关系，网格会把它对齐。

连杆件 / 改杆件

  1. 依次点两个节点 → 连成一根杆件
  2. 点已有杆件（或双击它）→ 改成下面选的截面与类型

画布上实线 = 能传弯矩的"梁"，虚线 = 只受轴力的"二力杆"。

设支座

  1. 点一个节点 → 支座按 无 → 铰支 → 滚动铰 → 固支 循环切换
  • 铰支：不能移动、可以转动 —— 竖向 + 水平都约束
  • 滚动铰：能水平滑动 —— 只约束竖向
  • 固支：不能移动也不能转动

至少留一个支座约束水平位移，否则整座桥会"滑走"（求解器会报机构）。

设加载点

  1. 点一个节点 → 在"是加载点 / 不是加载点"之间切换

砝码只能放在加载点上；「跨中集中力」会自动挑最靠近跨中的那个加载点。

删除

  1. 点节点 → 删掉它和所有与它相连的杆件
  2. 点杆件中段 → 只删这一根杆件
  3. 或把鼠标移到目标上按 Delete

删除后编号会重排，删错了点下面「撤销上一步」。
